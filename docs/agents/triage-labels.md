# Triage Labels

The skills talk about five triage roles. This file maps those roles to the label strings this repo's issue tracker uses.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | A maintainer needs to look at this issue |
| `needs-info`               | `needs-info`         | Waiting on the reporter for more details |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Needs a human to implement it            |
| `wontfix`                  | `wontfix`            | Will not be done                         |

When a skill names a role (for example "apply the AFK-ready triage label"), use the matching label string from this table.

Edit the right-hand column to match the words you actually use.
